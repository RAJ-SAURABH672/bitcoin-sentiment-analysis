\# Bitcoin Fear \& Greed vs Hyperliquid Trader Performance



\*\*A Complete Data Science Project for Primetrade.ai Hiring Assignment\*\*



\---



\### 📋 Project Overview



Hey there! 👋



This project explores the relationship between \*\*Bitcoin market sentiment\*\* (Fear \& Greed Index) and \*\*real trader performance\*\* on the Hyperliquid perpetuals exchange.



The goal was to uncover hidden patterns in how traders win or lose depending on whether the market is in Fear, Neutral, or Greed phase.



\---



\### 🎯 Objective



\- Understand trader PnL, win rate, position sizing, and risk behavior across different sentiment regimes.

\- Discover actionable insights for sentiment-aware trading strategies.

\- Showcase clean end-to-end data science workflow.



\---



\### 📁 Datasets Used



1\. \*\*Fear \& Greed Index\*\* (`fear\_greed\_index.csv`)

2\. \*\*Hyperliquid Historical Trader Data\*\* (`historical\_data.csv`) — 200K+ records



\---



\### 🛠️ Tech Stack



\- Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly

\- Scikit-learn \& Statistical Analysis

\- Jupyter Notebook
